# Hotel Booking System

A full-stack Hotel Booking Web Application developed using
Java, Spring Boot, React.js, and MySQL.

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Security
- JWT Authentication
- Hibernate / JPA
- MySQL

### Frontend
- React.js
- JavaScript
- HTML
- CSS

## Project Structure

hotel-booking-system/
│
├── backend/
│   └── Spring Boot Application
│
├── frontend/
│   └── React Application
│
├── .gitignore
└── README.md

## Features

- User Authentication
- Room Management
- Room Booking
- User Management
- Booking Management

## Installation and Setup

### Backend
1. Navigate to the backend folder.
2. Configure your MySQL database.
3. Run the Spring Boot application.

### Frontend
1. Navigate to the frontend folder.
2. Install dependencies using npm install.
3. Start the application using npm run dev.
